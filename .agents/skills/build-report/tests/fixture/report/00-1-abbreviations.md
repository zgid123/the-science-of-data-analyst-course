# List of Abbreviations

The abbreviations below are listed in alphabetical order, each with its full form and its role in this report.

| Abbreviation | Full form | Role in this report |
| :---- | :---- | :---- |
| ACER | Average classification error rate | Non-ISO average of APCER and BPCER used by competitions |
| APCER | Attack presentation classification error rate | Share of attack presentations of one PAI species accepted as bona fide |
| AUC | Area under the receiver operating characteristic curve | Threshold-free score of cross-dataset tests |
| AWS | Amazon Web Services | Industrial research lab behind the remote anti-spoofing threat model |
| BPCER | Bona fide presentation classification error rate | Share of bona fide presentations rejected as attacks |
| CDC | Central difference convolution | Operator of CDCN that adds a gradient term |
| CDCN | Central Difference Convolutional Network | Landmark Era-2 method |
| CEN | European Committee for Standardization | Publisher of CEN/TS 18099 on injection attack detection |
| CNN | Convolutional neural network | Backbone of deep PAD classifiers |
| CRFR-P | Covering a Random Facial Region followed by Proportional masking | Masking strategy of FSFM |
| CVPR | Conference on Computer Vision and Pattern Recognition | Venue of landmark PAD papers and challenges |
| D-EER | Detection equal error rate | Error rate where APCER equals BPCER |
| DfD | Deepfake detection | Digital-forgery task unified with FAS in FSFM |
| DIA | Digital injection attack | Attack that bypasses the sensor and injects digital content |
| ECCV | European Conference on Computer Vision | Venue of NUAA and of the ViT baseline in Table 2.8 |
| EER | Equal error rate | Operating point where both error rates are equal |
| ENISA | European Union Agency for Cybersecurity | Government source on remote identity proofing threats |
| EULA | End user licence agreement | Access condition of research datasets |
| FAR | False acceptance rate | Error term of HTER |
| FAS | Face anti-spoofing | Face-specific PAD task in FSFM |
| FATE | Face Analysis Technology Evaluation | NIST evaluation programme that includes the PAD benchmark |
| FF++ | FaceForensics++ | Deepfake dataset used for training and ablations |
| FNMR | False non-match rate | Genuine attempts rejected by the comparison stage |
| FRR | False rejection rate | Error term of HTER |
| FRTE | Face Recognition Technology Evaluation | NIST recognition track after the 2023 split |
| FRVT | Face Recognition Vendor Test | NIST face programme until its 2023 split into FRTE and FATE |
| HTER | Half total error rate | Average of FAR and FRR in cross-dataset tests |
| IAPAR | Impostor attack presentation accept rate | Newer name of IAPMR |
| IAPMR | Impostor attack presentation match rate | Share of impostor attack presentations that reach a match |
| ICCV | IEEE International Conference on Computer Vision | Venue of FLIP |
| IEC | International Electrotechnical Commission | Joint publisher of ISO/IEC 30107 |
| IR | Infrared | Sensor modality of multi-modal datasets |
| ISO | International Organization for Standardization | Joint publisher of ISO/IEC 30107 |
| LBP | Local binary pattern | Micro-texture descriptor of early PAD |
| LBP-TOP | LBP from Three Orthogonal Planes | Dynamic-texture extension of LBP to video |
| MAE | Masked autoencoder | Architecture of the FSFM reconstruction branch |
| MIM | Masked image modelling | Self-supervised reconstruction objective of FSFM |
| NAS | Neural architecture search | Search method behind CDCN++ |
| NIR | Near-infrared | Wavelength band used by dedicated PAD cameras |
| NIST | National Institute of Standards and Technology | United States agency behind the FATE PAD benchmark |
| NVLAP | National Voluntary Laboratory Accreditation Program | NIST programme that accredits iBeta |
| OTP | One-time password | Non-biometric authentication method for smaller transfers |
| PAD | Presentation attack detection | Subject of the report |
| PAI | Presentation attack instrument | Characteristic or object used in an attack |
| RGB | Red, green and blue | Colour images from standard consumer cameras |
| RIAPAR | Relative IAPAR | Metric added in ISO/IEC 30107-3:2023 that adds FRR to IAPAR |
| rPPG | Remote photoplethysmography | Pulse signal recovered from face video |
| SBV | State Bank of Vietnam | Central bank that issued the biometric mandate |
| SWIR | Short-wave infrared | Spectral band in which skin shows characteristic remission |
| ViT | Vision Transformer | Transformer backbone for images |
| VND | Vietnamese dong | Currency of the transfer thresholds |
