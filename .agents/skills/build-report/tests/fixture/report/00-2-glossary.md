# List of Terms

The terms below are listed in alphabetical order, each with its meaning in this report.

| Term | Meaning in this report |
| :---- | :---- |
| Attack potential | The effort an attack requires, rated in the Common Criteria by elapsed time, expertise, knowledge of the target, window of opportunity and equipment (Section 1.1.3) |
| Auxiliary supervision | Training a detector to predict a physical signal such as a depth map or an rPPG signal in addition to the live-or-spoof label (Sections 1.3.3 and 2.2.1) |
| Bona fide presentation | An interaction of the capture subject with the capture subsystem in the way the policy of the biometric system intends (Section 1.1.1) |
| Confirmation letter | The document iBeta issues after a PAD test, confirming conformance with its NVLAP-audited ISO/IEC 30107-3 procedure; not a product certification (Section 3.2) |
| Cross-dataset testing | Training on one or more source datasets and testing on an unseen target dataset, the main measure of generalisation (Section 1.3.4) |
| Deepfake | A face image or video manipulated or synthesised with generative models, delivered as digital content rather than shown to a camera (Sections 1.1.4 and 2.3.2) |
| Domain generalisation | Learning features that hold across several source datasets so that a detector works on an unseen dataset (Section 2.3.1) |
| Foundation model | A model pretrained once on broad data and then adapted with a small head to several downstream tasks (Part 4) |
| Instance discrimination | A self-supervised objective that aligns the representations of different views of the same image; in FSFM, a masked view and the full face (Section 4.2.3) |
| Liveness detection | The common name for PAD methods that look for signs of life, such as blinks, motion or the blood pulse (Sections 1.3.2 and 2.1.2) |
| O/C/I/M protocol | The leave-one-out evaluation over OULU-NPU, CASIA-FASD, Idiap Replay-Attack and MSU-MFSD, with three datasets for training and one unseen dataset for testing (Section 1.3.4) |
| PAI species | A class of presentation attack instruments made with a common production method, such as printed photographs (Section 1.1.1) |
| Presentation attack | A presentation to the biometric data capture subsystem with the goal of interfering with the operation of the biometric system (Section 1.1.1) |
| Remote identity verification | Verifying a person's identity through their own phone or computer camera, the setting in which injection attacks grew (Section 2.3.2) |
| Self-distillation | Training an online network to match a slowly updated copy of itself, the target network, without labels (Sections 4.2 and 4.2.3) |
| Serial and parallel integration | The two ways of placing PAD in a biometric system: as a gate before comparison, or beside the comparator with fused outputs (Section 1.2.3) |
| Zero-shot | Testing a model on a dataset or attack type that it did not see in training (Sections 1.3.3, 2.3.1 and 4.2.4) |
