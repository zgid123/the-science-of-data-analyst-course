## 1.1. Problem

The system under study is reached through an application programming interface (API), and each API call is recorded with its outcome [1]. Table 1.1 lists the two outcomes that the report distinguishes.

**Table 1.1. Outcomes of a call**

| Outcome | Meaning |
| :---- | :---- |
| Success | The call returns the requested result |
| Failure | The call returns an error code |
