# Domain glossary: data cleaning and data quality

Data cleaning, data-quality theory, error types, cleaning workflows and tools such as OpenRefine, and the neighbouring tasks of data preparation for analysis. Select it for reports on data cleaning, data quality, data preparation or LLM agents that work on tables. Tool names and operation names (OpenRefine, Trifacta, GREL, Jython, mass_edit, regexr_transform, upper, trim, numeric, date) stay in English as written; this file fixes the terms around them.
