## Wording settled by human review (lessons.md L4)

| English | Vietnamese | Usage | Replaces |
| --- | --- | --- | --- |
| foundation (basis of a report or section) | cơ sở | "làm cơ sở cho toàn bộ báo cáo"; "nền tảng" stays for foundation models and platforms | |
| strengths and limitations | ưu điểm và hạn chế | Preferred by human review over "điểm mạnh và điểm hạn chế" | |
| bypass (the sensor) | bỏ qua | "kẻ tấn công bỏ qua cảm biến" | |
| hardware / software approach (a kind of solution) | giải pháp phần cứng / giải pháp phần mềm | Preferred by human review over "tiếp cận phần cứng"; "cách tiếp cận" stays for a research approach | |
| show (that a study shows) | chứng minh rằng / cho thấy | "chứng minh rằng" when a study demonstrates a claim | |
| adopt / follow (a standard's terminology) | áp dụng | "áp dụng hệ thuật ngữ chuẩn" | |
| set out (what a part or section does) | trình bày | "Phần này trình bày …" | |
| covers (what a standard specifies) | quy định về | "ISO/IEC 19989-3 quy định về PAD" | |
| distinguish A from B | phân biệt A với B | Preferred by human review over "vạch ranh giới giữa" | |
| mimic (what a replay imitates) | mô phỏng | "bị video phát lại mô phỏng" | |
| record (what a sensor captures) | ghi nhận | "cảm biến ghi nhận trực tiếp bằng chứng vật lý" | |
| structure of the section (introduction) | cấu trúc của Mục … như sau: | Followed by the subsections separated by semicolons | |
| in summary (closing paragraph) | Tóm lại, | Opens a separate closing paragraph | |
| limit (bound) / limitation (weakness) | giới hạn / hạn chế | Keep the two apart: a limit is a bound, a limitation a weakness | |
