# Common glossary: standards and regulation

International standards, certification, and the hierarchy of Vietnamese legal documents. Loaded for every report.

| English | Vietnamese | Usage | Replaces |
| --- | --- | --- | --- |
| standard / international standard | tiêu chuẩn / tiêu chuẩn quốc tế | Keep codes: ISO/IEC 30107-3:2023 | |
| technical specification | đặc tả kỹ thuật | Keep codes: CEN/TS 18099 | |
| part (of a standard) | phần | "ISO/IEC 30107 Phần 3" | |
| edition / revision | phiên bản / bản sửa đổi | "phiên bản thứ hai" | |
| normative / informative | chuẩn tắc / tham khảo | Annex labels as in TCVN: "(quy định)" / "(tham khảo)"; "quy chuẩn" means a technical regulation (QCVN) | |
| standards body | tổ chức tiêu chuẩn | | |
| certification / certification scheme | chứng nhận / chương trình chứng nhận | | |
| certified | được chứng nhận | | |
| conformance / compliance testing | kiểm tra sự phù hợp | | |
| accredited test laboratory | phòng thử nghiệm được công nhận | | phòng thí nghiệm được công nhận |
| accreditation | công nhận | | |
