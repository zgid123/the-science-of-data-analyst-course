# Personal writing

Use this guide for personal reports, reflections, letters, journals, and similar first-person documents. For DOCX, apply [DOCX formatting and production](docx.md) unless the user specifies another style. For LaTeX, use [LaTeX production](latex.md) with the requested or existing project style.

- Follow the [writing voice](../SKILL.md#writing-voice): write naturally, use plain English for English documents, avoid formulaic AI phrasing. Apply punctuation preferences to new prose while preserving supplied wording during format-only work. Preserve the user's voice, point of view, and level of formality. Ask only when audience or purpose is essential and cannot be inferred.
- Organize around the reader's purpose: for example, a short opening, a small number of clear sections, and a close when useful. Do not force academic chapters, methods, citations, or formal conclusions onto personal writing.
- Use only details the user supplied or explicitly authorized. Do not invent experiences, emotions, names, events, or commitments.
- When editing, preserve the meaning and tone unless the user asks for a rewrite. Make uncertainty clear instead of making a personal account sound more certain than it is.
- If the user requests style or layout only, retain their text and do not draft new body content.
