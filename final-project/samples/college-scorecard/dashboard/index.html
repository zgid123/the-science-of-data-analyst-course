College Scorecard: outcome definitions before student-risk labels

Feasibility and contextual analysis only. Institution/program aggregates do not contain student assessment trajectories or future academic-risk linkage. Reporting cohorts differ; 1 − completion/retention is not an individual Fail/Withdrawn label.

Which outcome and denominator are being compared?

Coverage denominator is all snapshot institutions in the selected sector, including inapplicable metric families. Completion uses full-time first-time cohorts; retention uses prior-year return cohorts. IPEDS level defines reporting family; PREDDEG is not used to force the population.

Institution average versus relevant cohort average

These compare different estimands. D150 cohort sizes weight completion; pooled retention uses matching pooled retention denominators. UGDS is not a matching denominator. Non-pooled retention has no matching cohort count in these selected local fields. Rounded rates make weighted totals approximate.

Do tiny completion cohorts change the interpretation?

Minimum cohort restrictions change the population; small cohorts are not automatically invalid. Observe both institution and cohort-weighted means.

Same institution does not mean the same students

These ecological rate correlations cannot identify individual risk. Non-completion can include transfer, later completion or different cohorts; it is not a confirmed Fail/Withdrawn label.

What values are missing or suppressed?

NULL includes unreported/inapplicable data; PrivacySuppressed is never recoded to zero. Pooled and unpooled rates have different cohorts. Exact per-field local cohort vintage is not verified.

Why the program table cannot create student warning labels

No student assessment events, deadlines, score availability or future academic result linkage is present. Program rows are not independent student records and are not joined to inflate institutional denominators. No risk score or alert accuracy is shown.
