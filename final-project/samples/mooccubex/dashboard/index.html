MOOCCubeX: what the local assessment-content snapshot can support

Feasibility assessment. The local files contain course resources and semantic/help relations, with no linked student assessment trajectories or later academic outcomes. Content evidence is not a validated student warning.

Which links needed for early warning are actually present?

Missing user–problem events and future outcomes block student warnings. Neither shared concepts, chapter positions, help queries nor reply edges supplies that missing evidence.

How uneven is assessment content?

The unit is a course resource list. Exercise containers group problems; they are not submissions, required obligations or timed deadlines. Quantiles show skewness that the mean hides.

Can concepts establish applicable assessment opportunities?

Concept overlap is semantic context and does not directly map exercise containers to problems. It cannot justify a many-to-many course/problem join for students.

Does manual labeling overstate exercise coverage?

Only matched manually labeled courses enter these field summaries; 85 manual course IDs are absent from the course entities. Courses may belong to multiple fields, so field counts cannot be summed as independent courses.

Repeated edges are not repeated student attempts

Unique-pair coverage removes exact duplicate relation edges while preserving raw counts. User help-query types have no correctness, deadlines or academic outcomes. No risk score is shown because none is supported.
