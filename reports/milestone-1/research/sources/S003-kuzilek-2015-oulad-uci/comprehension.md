# S003 – Open University Learning Analytics Dataset [Dataset], UCI Machine Learning Repository

## Summary in my own words

The UCI Machine Learning Repository page is the dataset record for OULAD, donated on 20 December 2015 with DOI 10.24432/C5KK69. It describes the data as seven selected modules and more than 30,000 students, with presentations starting in February (B) and October (J), stored as several linked CSV files. It flags that the data have missing values, lists the file sizes (studentVle.csv is the largest at 432.8 MB) and states the CC BY 4.0 licence that allows sharing and adaptation with credit. It gives the recommended citation, which matches the outline's reference [3].
