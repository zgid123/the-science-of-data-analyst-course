## What the brief asks of the team for AI-written code

- The brief does not accept AI-generated code that members cannot explain (section 11, "Coding prototype"). Each script is short and commented; `README.md` in this folder lists what each one does. The team should read and rerun them before submitting.
- No metric, threshold, plot or result in this folder was written by hand or generated as an expectation: every number in the reports is printed by a script into a step log and saved under `results/`, and every report table is written into the report by `common/fill_report_tables.py`.
- No synthetic record or label was used as evidence. Synthetic toy inputs appear only in `common/tests/test_lib.py` and `common/tests/test_aq2_model.py`, labelled as such, to test code paths.
- The first run contained an error of method that the assistant did not catch and a team member's independent analysis did (finding 1). An independent second analysis by a person remains the strongest check on AI-written analysis code.
