# List of Abbreviations

The abbreviations below are listed in alphabetical order, each with its full form and its role in this report.

| Abbreviation | Full form | Role in this report |
| :---- | :---- | :---- |
| ABROCA | Absolute between-ROC area | Threshold-free measure of differential discrimination between a group and the rest (Appendix IX) |
| AI | Artificial intelligence | Simulated stakeholder interviews (Section 1.1), assistant under the team's checks (Section 13); subject of the law in Section 12.1 |
| AQ | Analytical question | AQ1–AQ4, the four final questions (Section 3) |
| CMA | Computer-marked assessment | Task type counted in the early-sign rule (Section 2.1) |
| CRISP-DM | Cross-Industry Standard Process for Data Mining | Process model behind the project's phases (Appendix XVI) |
| CSV | Comma-separated values | File format of the seven OULAD tables (Appendix IV) |
| DOI | Digital object identifier | Persistent identifier of the pinned OULAD release (Appendix IV) |
| FAIR | Findable, accessible, interoperable and reusable | Data principles cited for the reproducibility of the work (Appendix XVI) |
| IMD | Index of Multiple Deprivation | Source of the deprivation band used in the fairness checks (Appendix VI) |
| KPI | Key performance indicator | Completion rate and the two contact rates (Section 2.1) |
| LMS | Learning management system | The university's platform whose records the project would use (Section 1) |
| MOOCs | Massive open online courses | Course type of rejected candidate datasets and published studies (Appendices I and IV) |
| OULAD | Open University Learning Analytics Dataset | The project's dataset, prepared as OULAD-N04-prepared-1.0 (Section 1.2) |
| ROC | Receiver operating characteristic | Curve behind a secondary discrimination metric of AQ3 (Appendix IX) |
| SHA-256 | Secure Hash Algorithm, 256-bit | Checksums that pin the OULAD download (Section 4.1) |
| SMART | Specific, measurable, achievable, relevant and time-bound | Form of the project goal (Section 2) |
| TMA | Tutor-marked assignment | Task type whose late submission is an early sign (Section 2.1) |
| TRIPOD+AI | Transparent Reporting of a multivariable prediction model for Individual Prognosis Or Diagnosis, updated for AI | Reporting guideline that frames the evaluation (Section 9) |
| UCI | University of California, Irvine | Repository of three rejected candidate datasets (Section 4.1) |
| UK | United Kingdom | Country of the OULAD modules (Section 5) |
| UNESCO | United Nations Educational, Scientific and Cultural Organization | Author of the guidance on generative AI (Section 13.2) |
| UTC | Coordinated Universal Time | Time standard of the access date and run logs (Appendices IV, VII and X) |
