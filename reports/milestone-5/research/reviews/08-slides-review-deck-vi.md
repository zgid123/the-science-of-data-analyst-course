# slides-review-deck-vi

## Native review

Reviewer: a native Vietnamese reader who did not translate the deck, so the reading is fresh. Scope: every value in `slides_milestone5_30_vi.py` (607 strings: slide text, chart labels and presenter notes) and the five Vietnamese chart images. The review ran four passes: reader (deck text only, English closed), fidelity (each value against its English key), the checklist of `review.md` section 3, and a slide-only read without the notes. Keys are unchanged; 83 values were revised. Two Vietnamese-only layout changes went into `build_slides_milestone5_30.py`, both guarded by `kit.LANG == "vi"`: the group counts on slide 17 use the Vietnamese thousands separator (they showed "1,488", which reads as a decimal), and the take-home box on slide 29 is taller so its two-line Vietnamese text fits. The English deck is unchanged.
