# Final Project Traceability Matrix (design file, T09)

Working design file for report Section 11.1 (brief section 3). One row per final Analytical Question (AQ1–AQ4); the
columns are those of the brief. Cells hold report-facing wording in the team voice; the claim IDs and result files
behind each cell are in the Sources list after each table. A link without evidence is written GAP or N.A. with its
reason. Conflict resolutions behind individual cells: `conflict-resolutions.md` (R-numbers); new Change Log entries:
`change-log-m5.md` (C15–C17).

Status rule used for the last column (brief section 3): **Answered** = the whole final AQ is answered with real results
on its stated population; **Partial** = real results answer the core, while a named part waits for data or for a
later step; **Deferred** = no result yet, the design is complete and the answer waits for a named step; **Dropped** =
the question is abandoned. No AQ is Dropped.
