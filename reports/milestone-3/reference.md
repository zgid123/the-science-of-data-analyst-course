## Scope and rules

- Understand before preparing: dataset semantics (population, unit, keys, outcome, time, measurement, codes,
  sensitive attributes) and evidence-based profiling come before any change to the data.
- Raw is immutable; every change creates a new file in `data/interim/` or `data/processed/`; every step is a script
  that reruns from raw; every number in the report traces to a file in the package or `logs/`.
- Question-driven preparation: each transformation serves an AQ, KPI, target or planned technique; every quality
  issue gets a decision with a rationale (Data Quality Issue Log, Preparation Decision Matrix).
- AQ–Data fit rated GREEN / YELLOW / RED; missing values are separated from missing variables; synthetic data never
  fills a missing concept, label or intervention (brief section 8.3).
- Predictive readiness: prediction points (end of week 2 = day 13, end of week 4 = day 27, from Milestone 2), only
  pre-cut-off features, entity and time split, transforms fitted on the training partition, no model tuning.
- The OULAD exploration (`datasets/oulad/exploration/`: code, results, logs, REPORT.md) is reused where it answers a
  profiling question; every figure quoted in Milestone 3 is regenerated by the Milestone 3 package scripts.
- AI as data-dictionary interpreter, quality-checklist partner, code assistant, preparation critic, feature ideator
  and documentation assistant; every AI suggestion verified on the data and recorded in the AI Decision Log.
- Deliverables: report (A), updated traceability (B), preparation pipeline (C), Prepared Data Package (D),
  Controlled Change Log (E), AI Decision Log (F). Length: 8–12 pages of main content, appendices excluded. English
  source, Vietnamese twin.
