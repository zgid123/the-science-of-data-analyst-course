# S605 – OU Analyse project full details (Knowledge Media Institute)

## Summary in my own words

The KMi project page for OU Analyse (project timeline 1 August 2013 to 31 July 2015, the same years as the OULAD presentations) states how the system works: machine learning on demographic data and VLE activity, with models built and validated on previous presentations of a module and then applied to the presentation currently running. A weekly list of at-risk students goes to the module and Student Support teams. This is the readable replacement for S601 on the "train on the previous presentation" practice.

## Key facts

- Weekly at-risk lists – "A list of such students is communicated weekly to the module and Student Support teams"
- Two data types – "applying machine learning techniques to two types of data: student demographic data and dynamic data represented by their VLE activities"
- Training on previous presentations, applied to the running one – "Records of previous presentations are used to build and validate predictive models, which are then applied to the data of the presentation currently running."
- Project period – "Timeline:01 Aug 2013"
- Team includes the OULAD authors – "Participant(s):Zdenek Zdrahal, Jakub Kuzilek, Martin Hlosta"
- Builds on the Jisc Retain project (2010/2011) and an OU–Microsoft Research Cambridge project (2012/2013) – "builds on previous experience from the Jisc funded Retain in 2010/2011"
