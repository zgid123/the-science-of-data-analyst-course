# S300 – OU Analyse: Open University Learning Analytics dataset (official dataset pages, The Open University)

## Summary in my own words

The OU Analyse pages of The Open University are the provider's own landing pages for OULAD. They describe the data as anonymised records of courses, students and their VLE interactions for seven modules, with presentations starting in February (B) and October (J), stored as CSV tables linked by identifiers. The "open dataset more" page offers the latest version as a zip with an MD5 checksum, states the CC-BY 4.0 licence and asks users to cite the Scientific Data paper (S002). The pages render poorly for the converter; the text was obtained with WebFetch, partly as short verbatim quotes and partly paraphrased, so only the quoted strings serve as anchors.

## Key facts

- Anonymised dataset – "We introduce the anonymised Open University Learning Analytics Dataset (OULAD)."
- Content – "It contains data about courses, students and their interactions with Virtual Learning Environment (VLE)"
- Seven modules – "for seven selected courses (called modules)."
- Format – "The dataset consists of tables connected using unique identifiers. All tables are stored in the csv format."
- Latest version offered – "You can download the latest version of the OULAD here:"
- Licence – "This dataset is released under CC-BY 4.0 license."
- Clickstream table – "contains information about each student's interactions with the materials in the VLE."
- Citation requested: Kuzilek J., Hlosta M. & Zdrahal Z. (Scientific Data 2017; S002).
