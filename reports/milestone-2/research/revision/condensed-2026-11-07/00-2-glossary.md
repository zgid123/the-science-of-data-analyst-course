# List of Terms

The terms below are listed in alphabetical order with their meaning in this report and the section that defines them.

| Term | Meaning in this report |
| :---- | :---- |
| Controlled Change Log | The record of every change to the frozen Milestone 1 baseline, with its data evidence and effect (Appendix V) |
| Coverage (Full, Partial, None) | How far the collected data answer a question: fully, in part with stated limits, or not at all (Section 7.1) |
| Data Collection Package | The raw files, metadata and scripts that re-create the collected data (Appendix III) |
| Frozen baseline | The Milestone 1 goal, measures, questions, data needs and decisions, copied and checksummed before the search (Section 1.1) |
| Leakage | Use of information that is not yet known at the prediction point, which inflates measured accuracy (Section 2.3) |
| Module run (presentation) | One offering of an OULAD module, coded by year and start month: B for February, J for October; "course" refers to the university's courses (Section 6) |
| Must-have gate | A requirement a candidate dataset must meet whatever its score (Section 2.1) |
| Prediction point (data cut-off) | The last day whose data a list may use: the end of week 2 (day 13) for the week-3 list and the end of week 4 (day 27) for the week-5 list; the list reaches staff one week later (Section 2.3) |
| Structural verification | The check that collected files can be read and match their documentation, without cleaning or analysis (Section 6) |
